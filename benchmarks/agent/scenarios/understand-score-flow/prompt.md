`mode.ws` is an Overwatch Workshop game mode. Do not modify it.

Answer these questions about it by writing `answer.json` in this directory, with exactly these keys:

- `targetScore`: the number of points needed to win, as a number.
- `victoryRule`: the name of the rule that declares the winner.
- `scoreWriters`: the names of all rules that change the player variable `score`, sorted alphabetically.
- `unusedVariables`: the names of all declared variables that no rule ever reads or writes, sorted alphabetically.
