Create `mode.ws`, an Overwatch Workshop free-for-all game mode, in this directory.

Requirements:

- Every player is forced to play Soldier: 76.
- An elimination of another player scores one point for the attacker. Self-inflicted deaths score nothing.
- A HUD visible to everyone shows the winning score.
- The first player to reach 7 points wins the match.

Make sure the finished project is valid and has no remaining diagnostics.
