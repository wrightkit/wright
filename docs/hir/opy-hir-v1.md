# Opy HIR v1 historical pointer

Wright no longer owns or consumes an authoritative OPY HIR implementation.
The static OPY implementation was removed after the provider cutover; current
OPY syntax, semantics, HIR, compilation, and reconstruction contracts are owned
by [`opy-rs`](https://github.com/wrightkit/opy-rs).

The historical Wright decision that introduced this protocol remains in
[ADR-0005](../adr/0005-opy-hir-v1.md). The current OPY HIR contract, including
the retained v1 baseline and v2 migration, is documented by `opy-rs`.

This file is retained only as a compatibility pointer for older links. It is
not a current Wright architecture or protocol authority.
