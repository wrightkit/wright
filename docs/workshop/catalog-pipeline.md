# Workshop catalog pipeline historical pointer

Canonical Workshop catalog data, identities, localization, validation, and the
catalog update pipeline are owned by
[`workshop-rs`](https://github.com/wrightkit/workshop-rs).

Wright consumes the reviewed `workshop-rs` contract and does not maintain a
second catalog generator, provenance record, or update procedure. Current
catalog provenance and update instructions belong in the owner repository.

The historical Wright cutover remains in ADRs and Issues/PRs. This file is
retained only as a compatibility pointer for older links.
